# Phase E: GPL-only code

The project is distributed under GPL-3.0-or-later. Parts of it are code taken from
ct-recomp (MIT) and its vendored cores, zelda3's SNES core (MIT) and ares's SPC700 (ISC).
Those licenses require their notices to stay, so those files keep MIT or ISC lines; see
[REUSE.toml](../REUSE.toml).

The long-term goal is code that is GPL-only: every MIT or ISC part replaced by our own
implementation, so that their notices can go.

**Status: planned, not started.** The priority now is playability and release builds.
This page is the inventory and the order of work.

## Rules for the rewrite

- **Clean-room, from specifications:** fullsnes, the WDC 65816 data sheet and the SPC700
  and S-DSP documentation. The old file is not open while its replacement is written.
  The replacement is not a line-by-line paraphrase, because that would stay a
  derivative work, and its license would stay.
- **The test suite is the specification of behaviour:** frame hashes, lockstep and
  module parity. A component is done when the suite passes with the new code and the
  old file is deleted.
- **Notices:** the file gets a GPL-only SPDX header. Its REUSE.toml entry and its
  THIRD_PARTY.md entry go.
- **Tests too:** test files carried from upstream count as well. They are rewritten
  last, after the code they test.

## Order

1. **Runtime support files:** small, isolated, and they prove the workflow.
2. **The SPC700 and S-DSP core,** checked against the audio tests and recorded WAV
   hashes.
3. **The runtime CPU:** interpreter, ops and cycles. The interpreter/native lockstep is
   the check.
4. **The bus, scheduler and adapter.**
5. **The PPU.** Done after the scheduler because its interface to the scheduler is set
   by then. The HD-2D G-buffer outputs are part of its specification.
6. **The recompiler, then `game/ct` metadata,** regenerated with our own tools.
7. **The remaining tools, then tests, build files and docs.**

Each step is its own branch, merged only with every test green and the frame hashes
unchanged.
